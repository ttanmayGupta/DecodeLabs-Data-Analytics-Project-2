# DecodeLabs Data Analytics - Project 2: Exploratory Data Analysis (EDA)

## Objective
Analyze a sales dataset to understand patterns, trends, distributions and outliers.

This follows the Project 2 requirements:
- Calculate basic statistics: count, mean and median
- Identify trends and outliers
- Summarize key observations

## Files
- `sales_data.csv` - dataset
- `eda_project.py` - complete Python EDA code
- `requirements.txt` - required Python libraries
- `graphs/` - generated visualizations
- `EDA_Report.md` - final analysis/report

## Tools
- Python
- Pandas
- Matplotlib
- NumPy
- VS Code

## How to Run
1. Open this folder in VS Code.
2. Open Terminal.
3. Run:
   `pip install -r requirements.txt`
4. Then run:
   `python eda_project.py`
5. Check the terminal output.
6. Open the `graphs` folder to see the charts.

## EDA Results from the Included Dataset
- Total records: 48
- Mean sales: ₹433,059.97
- Median sales: ₹347,924.23
- Mean quantity: 17.60
- Median quantity: 15.00
- Detected sales outliers: 1
